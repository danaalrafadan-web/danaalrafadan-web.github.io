# ARCHIVE AI | أرشيف

منصة ذكية لإدارة وأرشفة المستندات والبحث فيها وتحليلها. صُمّمت لتناسب بيئة العمل في المؤسسات الإعلامية.

> **تنبيه:** هذا نموذج أولي مستقل، اقترحتُه لجهة التدريب. ليس منتجًا رسميًا للمجموعة السعودية للأبحاث والإعلام (SRMG)، ولا يستخدم شعارها أو أي معلومات داخلية لها. كل المستندات والأسماء والإيميلات تجريبية وخيالية.

## طريقة التشغيل

### الطريقة الأولى: خادم محلي (الأفضل)

1. ثبّت [Python](https://www.python.org/downloads/) إذا لم يكن مثبتًا عندك.
2. افتح الطرفية (Terminal أو PowerShell) داخل مجلد `archive-ai`.
3. شغّل هذا الأمر:

   ```bash
   python -m http.server 5610
   ```

4. افتح المتصفح على العنوان `http://localhost:5610`.
5. لإيقاف الخادم اضغط `Ctrl + C` في الطرفية.

### الطريقة الثانية: فتح الملف مباشرة

افتح `index.html` بالنقر المزدوج عليه. أغلب الميزات تشتغل بهذه الطريقة، لكن الخادم المحلي أضمن لرفع الملفات وتخزينها.

> يحتاج الموقع إلى اتصال بالإنترنت أول مرة، لتحميل الخطوط ومكتبة الرسوم البيانية ومكتبتي استخراج النصوص.

## خطوات مقترحة لعرض المشروع على المشرف

1. **شاشة الترحيب**: تظهر أول ما يفتح الموقع، ثم تنتقل وحدها إلى لوحة التحكم.
2. **لوحة التحكم**: بطاقات إحصائية، ورسم بياني للنشاط تقدر تغيّر مدته (30 يومًا، 6 أشهر، سنة)، وتوزيع الملفات حسب التصنيف. اضغط على أي تصنيف لتنتقل لملفاته.
3. **البحث الذكي**: اكتب مثلًا `الميزانية` أو `budget`. لاحظ أن البحث يشمل اللغتين، وأن الكلمات المطابقة تتلوّن، وأن لكل نتيجة نسبة ارتباط. جرّب الفلاتر والترتيب.
4. **اسأل الأرشيف**: من تبويب المحادثة اسأل: «كم عدد التقارير في الأرشيف؟» أو «ما أحدث الملفات المالية؟».
5. **إدارة الملفات**: اسحب ملف PDF أو Word أو Excel أو PowerPoint إلى منطقة الرفع. النظام يستخرج نص الملف، ويصنّفه تلقائيًا، ويقترح كلماته المفتاحية وملخصه. بعدها تقدر تعدّل بياناته أو تنزّله أو تحذفه.
6. **التحليل الذكي**: حلّل الملف اللي رفعته، أو اضغط «نص تجريبي عربي»، ثم نزّل التقرير.
7. **الصلاحيات**: من قائمة الحساب أعلى الصفحة اختر «ريم الدوسري» (قراءة فقط)، ولاحظ أن الرفع والحذف وسجل النشاط تُقفل.
8. **سجل النشاط**: كل عملية سويتها في الخطوات السابقة تظهر هنا بتاريخها ووقتها.
9. **اللغة**: زر `English` يحوّل الواجهة كاملة للإنجليزية وبالاتجاه من اليسار لليمين.

لإرجاع البيانات لحالتها الأصلية: قائمة الحساب ← «إعادة ضبط البيانات التجريبية».

## ما الذي يعمل فعليًا

| الميزة | التنفيذ |
|---|---|
| رفع الملفات | قراءة فعلية للملف، وتخزينه في المتصفح (IndexedDB)، والتنزيل يرجّع الملف الأصلي نفسه |
| استخراج النص | PDF.js لملفات PDF، وJSZip لملفات DOCX وPPTX وXLSX |
| البحث | توحيد الحروف العربية (الهمزات والتاء المربوطة والتشكيل)، وتجذيع خفيف، وترتيب النتائج بالأوزان، ومرادفات بين العربي والإنجليزي |
| التصنيف التلقائي | مطابقة النص مع قاموس كلمات لكل تصنيف، مع نسبة ثقة |
| التلخيص | تلخيص استخلاصي: يختار أهم الجمل حسب تكرار كلماتها |
| الحفظ | البيانات في localStorage، فتبقى بعد تحديث الصفحة |

**عن الذكاء الاصطناعي:** «البحث الذكي» و«التحليل الذكي» هنا خوارزميات نصية تشتغل داخل المتصفح، وليست نموذج ذكاء اصطناعي حقيقي. الواجهة توضح هذا للمستخدم. لو حبيت تربطها لاحقًا بخدمة ذكاء اصطناعي فعلية، المكان المناسب هو الدوال `AA.analyze` و`AA.summarize` في ملف `js/engine.js`.

المستندات التجريبية ما لها ملفات أصلية، فلما تنزّل واحد منها ينزل لك ملف نصي فيه بياناته. أما الملفات اللي ترفعها أنت فتنزل كما هي.

## هيكل المشروع

```
archive-ai/
├── index.html          الصفحة وشاشة الترحيب
├── css/styles.css      التصميم كامل (المتغيرات، المكونات، الصفحات، التجاوب)
└── js/
    ├── core.js         اللغة، تنسيق التواريخ والأرقام، الأيقونات
    ├── data.js         التصنيفات، الأدوار والصلاحيات، البيانات التجريبية
    ├── engine.js       محرك البحث والتحليل واستخراج النصوص
    ├── store.js        الحفظ، الصلاحيات، سجل النشاط، تخزين الملفات
    ├── ui.js           التنبيهات، النوافذ، الشارات، إعدادات الرسوم
    ├── app.js          الهيكل العام، التنقل، إجراءات المستندات
    └── pages/          صفحة لكل قسم: dashboard, search, files, insights, users, activity
```

لإضافة صفحة جديدة: أنشئ ملفًا في `js/pages/` فيه `AA.pages.اسم = { title, render, mount }`، ثم أضف اسمها في `ROUTES` وفي القائمة داخل `app.js`.

## التقنيات

HTML5 وCSS3 وJavaScript بدون أي إطار عمل، مع:
- [Chart.js](https://www.chartjs.org/) 4.4.1 للرسوم البيانية

- خطّا IBM Plex Sans Arabic وSpace Grotesk من Google Fonts
