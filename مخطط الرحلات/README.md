# مخطط الرحلات

## وش يسوي المشروع؟
صفحة وحدة تكتب فيها الوجهة وعدد الأيام والميزانية والاهتمامات، وتسأل الذكاء الاصطناعي المجاني (Cloudflare Workers AI)، وترجع لك برنامج رحلة يوم بيوم. إذا ما وصل رد، تعرض الصفحة «مثال جاهز».

الرابط: https://danaalrafadan-web.github.io/مخطط%20الرحلات/trip-planner.html

## وين ألقى AI_INSTRUCTIONS؟
انتقلت للـ Worker في مستودع [ai-worker](https://github.com/danaalrafadan-web/ai-worker)، في ملف `src/index.js` (وعندك في الجهاز: `worker/src/index.js`)، أول شي في الملف، بين هذين السطرين:

```
// ===== تعليمات الذكاء الاصطناعي: عدلها من هنا =====
...
// ===== نهاية التعليمات =====
```

تعليمات هذي الصفحة اسمها `trip` داخل `AI_INSTRUCTIONS`.

## كيف أعدلها؟
1. افتح `worker/src/index.js` وعدل السطر اللي تبيه داخل `trip`. مثلاً غير `اللهجة: مصريه` إلى `اللهجة: سعودية`.
2. احفظ الملف.
3. من داخل مجلد `worker` شغل الأمر `npx wrangler deploy`. الصفحة ما تحتاج تعديل، والرابط يبقى نفسه.

## ملاحظة
أي شي داخل الصفحة يقدر يشوفه اللي يفتحها، فلا تحط فيها كلمات سر أو معلومات شخصية.
