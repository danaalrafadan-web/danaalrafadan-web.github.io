# مساعد الدوام

صفحة ويب واحدة يكتب فيها الموظف سؤاله عن الحضور أو التأخير أو الاستئذان، والصفحة ترسل السؤال للذكاء الاصطناعي المجاني (Cloudflare Workers AI) وتعرض الرد باللهجة السعودية. إذا ما وصل رد، تعرض الصفحة «مثال جاهز».

القواعد (بيانات تجريبية):
- الدوام من 8 الصباح إلى 4 العصر
- التأخير المسموح 15 دقيقة
- الاستئذان ساعتين بالكثير

الرابط: https://danaalrafadan-web.github.io/مساعد%20الحضور/

## وين ألقى AI_INSTRUCTIONS؟
انتقلت للـ Worker في مستودع [ai-worker](https://github.com/danaalrafadan-web/ai-worker)، في ملف `worker/src/index.js`، أول شي في الملف، بين هذين السطرين:

```
// ===== تعليمات الذكاء الاصطناعي: عدلها من هنا =====
...
// ===== نهاية التعليمات =====
```

تعليمات هذي الصفحة اسمها `assistant` داخل `AI_INSTRUCTIONS`.

## كيف أعدلها؟
1. افتح `worker/src/index.js` وعدل السطر اللي تبيه داخل `assistant`. مثلاً غير `اللهجة: سعودية` إلى `اللهجة: مصرية`.
2. احفظ الملف.
3. من داخل مجلد `worker` شغل الأمر `npx wrangler deploy`. الصفحة ما تحتاج تعديل، والرابط يبقى نفسه.

ملاحظة: إذا غيرت أرقام القواعد، عدلها كمان في البطاقات الثلاث اللي فوق الصفحة (قسم `rules` في `index.html`).
