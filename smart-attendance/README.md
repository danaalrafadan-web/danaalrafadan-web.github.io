# نظام الحضور الذكي

صفحة حضور وانصراف مربوطة بقاعدة بيانات Supabase. الموظف يدخل بالإيميل وكلمة المرور، ويسجل حضوره واستراحته وانصرافه.

الرابط: https://danaalrafadan-web.github.io/smart-attendance/

## المساعد الذكي
يجاوب من لائحة الحضور وشرح النظام وسجل الموظف. السؤال وسجل الموظف يروحون للذكاء الاصطناعي المجاني (Cloudflare Workers AI)، وإذا ما وصل رد تعرض الصفحة «مثال جاهز».

## وين ألقى AI_INSTRUCTIONS؟
في الـ Worker في مستودع [ai-worker](https://github.com/danaalrafadan-web/ai-worker)، في ملف `src/index.js` (وعندك في الجهاز: `worker/src/index.js`)، أول شي في الملف، بين هذين السطرين:

```
// ===== تعليمات الذكاء الاصطناعي: عدلها من هنا =====
...
// ===== نهاية التعليمات =====
```

تعليمات المساعد اسمها `attendanceBot`، واللوائح وشرح النظام في `BOT_KNOWLEDGE` تحتها مباشرة.

## كيف أعدلها؟
1. افتح `worker/src/index.js` وعدل `attendanceBot` أو `BOT_KNOWLEDGE`.
2. احفظ الملف.
3. من داخل مجلد `worker` شغل الأمر `npx wrangler deploy`. الصفحة ما تحتاج تعديل.

## ملاحظة
كل البيانات تجريبية. لا تكتب معلومات شخصية في المساعد.
